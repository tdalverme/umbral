# Evidencia del quickstart foundation-runtime

Fecha: 2026-07-29. El recorrido local se ejecutó en el worktree con Python
3.13.14, Node 24.15.0 y npm 12.0.1. El harness completo pasó con 146 tests
Python, Ruff, mypy, arquitectura, migraciones offline, jobs/objects/recovery,
OpenAPI, cliente generado, lint, TypeScript, 13 tests Vitest y seis casos
Playwright recolectados.

El límite de 15 minutos sólo se afirma para el recorrido local ya instalado.
Docker/PostgreSQL/MinIO reales y la promoción remota requieren prerrequisitos
externos y no se declaran ejecutados.
